# Rental Agent Guide

## Reservation to checkout

1. Create a Rental Quotation or Rental Reservation.
2. Enter customer, driver, dates, locations, rental type, category, and extras.
3. Open the pricing breakdown and confirm the selected rule and adjustments.
4. Check availability and assign a vehicle.
5. Confirm driver age/license, required documents, deposit, and minimum payment.
6. Create the Rental Agreement.
7. Complete the checkout inspection, photos, odometer, fuel, keys, tools, and accessories.
8. Use the **Checkout** action. Do not manually force the vehicle or agreement status.

## Extension

Create a Rental Extension from the active agreement. The extension checks the next
reservation, prices only the new interval, and links a separate invoice. Never change
the original agreement end date or invoice to represent an extension.

## Return

Create the Rental Return, capture actual time, odometer, fuel, condition, inspection,
damage, fines, cleaning, and missing accessories. Review automated mileage/fuel/late
charges, deposit use, refund, and balance before completion.

## Error handling

Read the full validation message. It identifies the conflicting vehicle, rental,
reservation, maintenance record, document, or date. Correct the source record; do not
try to bypass the error in the browser.
