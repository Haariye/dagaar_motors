# Operations Guide

## Daily rental flow

1. Create a Rental Quotation or Rental Reservation.
2. Use **Check Availability** and assign a vehicle.
3. Confirm required documents, driver eligibility and deposit.
4. Create the Rental Agreement.
5. Complete checkout inspection, mileage and fuel capture.
6. Activate the agreement and generate the configured invoice.
7. Record extensions as new Rental Extension records.
8. Complete return inspection and final reconciliation.
9. Allocate or refund the deposit.
10. Close the agreement after all financial documents are settled.

## Non-negotiable controls

- Never lower an odometer without the authorized correction workflow.
- Never manually mark a sold vehicle available.
- Never rewrite an old rental period to price an extension.
- Never record a security deposit as sales revenue.
- Never bypass an availability or discount error in the browser.

## Vehicle profitability

All rental invoices, vehicle-sale invoices, purchase invoices, expenses and maintenance
records should carry the Motor Vehicle and its Project/Cost Center. The Vehicle
Profitability report then reconciles operational and ERPNext financial sources.
